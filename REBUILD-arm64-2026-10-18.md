# Rebuilding Ekho (Toisanese) on Apple Silicon, 2026-10-18

Machine: EventHorizon, macOS 26 (Darwin 25.6), arm64. Branch `arm64-rebuild-2026-10` in this repo.
Result: native arm64 `ekho` speaks Toisanese. Build took about 20 seconds once configured.

## Quick use

```sh
ekho -v toisanese -o /tmp/test.wav 一二三四五六七八九十零 && afplay /tmp/test.wav   # 3.6 s
ekho -v toisanese -s -40 -o /tmp/slow.wav 一二三四五六七八九十零 && afplay /tmp/slow.wav  # 6.0 s, slower
~/C/src/ekho/say-toisanese.sh "你好，我係你個仔"             # writes $TMPDIR/toisanese.wav and plays it
~/C/src/ekho/say-toisanese.sh -s -30 "你好，我係你個仔"       # slower
~/C/src/ekho/say-toisanese.sh --engine clips --gap 0.25 一二三四五六七八九十零   # no binary needed, 6.3 s
```

Always use `-o file.wav` and then `afplay`. This build has no PulseAudio, so `ekho` with no `-o` cannot play aloud.

## Exact commands that worked, in order

```sh
# 0. Homebrew libraries (already present on this Mac; all native arm64)
brew install espeak-ng libsndfile sox utf8cpp mpg123 autoconf automake libtool pkgconf

# 1. Keep the old Intel binary
cd ~/C/src/ekho
git checkout -b arm64-rebuild-2026-10
mv ekho ekho.x86_64

# 2. sonic (only so that ekho's -s speed option works), static lib into ~/.local
cd ~/C/src/sonic
git checkout -b arm64-rebuild-2026-10
make clean
make CFLAGS="-O2 -Wall -fPIC -I/opt/homebrew/include"
mkdir -p ~/.local/lib ~/.local/include
cp -p libsonic.a ~/.local/lib/ && cp -p sonic.h ~/.local/include/
# (only the .a is installed, so ekho links sonic statically; no dylib, no rpath)

# 3. ekho itself
cd ~/C/src/ekho
autoreconf -fi        # optional: the checked-in configure was stale; regenerated for tidiness
B=/opt/homebrew
./configure --prefix=$HOME/.local --without-pulseaudio \
  CPPFLAGS="-I$B/include -I$B/include/utf8cpp -I$HOME/.local/include" \
  LDFLAGS="-L$B/lib -L$HOME/.local/lib" CXXFLAGS="-O2"
make clean && make -j8
# configure warns "unrecognized options: --without-pulseaudio". Ignore it: the flag
# still sets with_pulseaudio=no, and config.h ends up with HAVE_PULSEAUDIO undefined.
# Leaving the flag off links libpulse, which can auto-spawn a PulseAudio daemon.

# 4. Shim so plain `ekho` works from any directory (no make install)
cat > ~/.local/bin/ekho <<'EOF'
#!/bin/sh
EKHO_DATA_PATH="${EKHO_DATA_PATH:-$HOME/C/src/ekho/ekho-data}" exec "$HOME/C/src/ekho/ekho" "$@"
EOF
chmod +x ~/.local/bin/ekho

# 5. Python helper's one optional dependency (pyenv myenv)
python3 -m pip install opencc-python-reimplemented
```

Check the result: `otool -L ~/C/src/ekho/ekho` should list only Homebrew mpg123, espeak-ng, libsndfile and system libs.

## What differed from the 2024 Intel recipe

- **No espeak-ng fork build, no pcaudiolib.** Ekho only calls espeak-ng's public API, so Homebrew's espeak-ng 1.52 works. pcaudiolib was only ever needed to build espeak-ng. The forks are untouched apart from a wip commit (below).
- **No PulseAudio.** 2024 routed sound through a PulseAudio daemon. Now Ekho writes a WAV and `afplay` plays it.
- **Nothing in `/usr/local` or `/usr/lib`.** Libraries are Homebrew (`/opt/homebrew`) plus `~/.local/lib/libsonic.a`.
- **Data path.** The binary finds `ekho-data` only from the repo folder or via `EKHO_DATA_PATH`. The shim sets it.
- **Traditional characters.** `ekho-data/toisanese_list` is mostly simplified characters. Ekho silently drops any character without an entry, e.g. 個. `tools/toisanese_say.py` swaps such characters for their simplified form (個 to 个) when that form has an entry, and prints anything still missing.

## Where things live

| What | Where |
|---|---|
| arm64 binary | `~/C/src/ekho/ekho` (old Intel one: `ekho.x86_64`) |
